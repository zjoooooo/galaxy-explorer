# Galaxy Explorer 🌌
デモページ
https://zjoooooo.github.io/galaxy-explorer/
<img width="1920" height="945" alt="Image_2026-07-04_141404_478" src="https://github.com/user-attachments/assets/ce6388f3-5854-4c13-9d6c-daccac89bf24" />

完全な 3D の**太陽系**、さまよう**彗星**、そして本物の**電波銀河ジェット**を備えた、インタラクティブなプロシージャル生成の**天の川銀河**。WebGL（three.js）だけでブラウザ上で完結します。バックエンドもビルド工程も、依存パッケージのインストールも API キーも不要 — ページを開くだけで探索できます。

銀河そのものは、読み込み時にコードで生成されます。**画像アセットはほとんど使いません** — 渦状腕も油絵の円盤も星団も、遠方銀河も超新星も、すべて数式です（大小マゼラン雲とケンタウルス座 A は、さらに 3 枚の CC BY 写真プレートから星の位置と色をサンプリングしています）。太陽系ではその上に、惑星・衛星・太陽向けの実際の NASA ベースの表面テクスチャを重ねています。

[MIT ライセンス](LICENSE)のもと、個人・商用・学術・教育を問わず**あらゆる用途で自由に利用できます**。


## ✨ 特徴

- **油絵のような天の川** — 銀河円盤は、読み込み時に GPU で描かれる一枚の油絵です。筆致が 4 本の渦状腕に沿って流れ、各腕の内側には暗いダストレーン、ピンク色の星形成領域が散らばり、コアはクリームがかった金色、縁はやわらかく溶けていきます。約 3 万個の星は遠くからは控えめに、近づくとまたたき始め、近くでは油絵が星空に席を譲ります。
- **銀河バルジ** — ゆっくりと「呼吸」する、なめらかなマルチスケールのグローコア。
- **ディープフィールドの星空** — またたく星野に加えて、約 170 個の小さな遠方銀河（楕円銀河、渦巻銀河、エッジオンの円盤銀河、不規則銀河）、豊かな銀河団、そしてアンドロメダ風の大きな隣人がひとつ — これらすべてをわずか 2 回のドローコールで描画します。
- **物理モデルに基づくアンビエントイベント** — ときおり流れ星や流星群、超新星が発生します。超新星は実際の光度曲線（t².³ で立ち上がり → 丸みを帯びたピーク → 2 段階の減光）に従い、4 本の回折スパイクの閃光を放ちます。
- **インタラクティブなビーコン** — クリック可能な約 30 個のマーカー（太陽系、いて座 A*、有名な星雲、星団、恒星、ブラックホール）。クリックすると詳細な 5 言語対応の情報カードが開き、選択した天体には光る 3D リングが表示されます。系外銀河に近づくと、その銀河固有の**銀河内天体**が現れます — 星形成領域、球状星団、超新星残骸、電波ジェットが、それぞれ専用のカードとともに登場します。天の川ビュー下部のガイドバーには銀河系内の 25 個すべてのビーコンが並び、探し回る必要はありません。
- **写真からサンプリングした近傍銀河** — 大小マゼラン雲とケンタウルス座 A は、星の位置と色を ESO／NOIRLab の実際の写真からサンプリングしています。マゼラン雲はレイマーチングによるボリューム（ドメインワープした 3D ノイズを 26 ステップ、二色は独立したノイズ場で混合）、ケンタウルス座 A のダストレーンは薄い縁で赤化する体積吸収の層です。系外銀河と天の川の腕の星はすべて「白く熱い芯 + 色付きの暈」で描かれ、系外銀河の星はサイズに上限があるので近づいても鋭い光点のままです。
- **電波銀河ジェット** — **ケンタウルス座 A** のジェットは彗星のイオンテール技法を借りています。粒子が脈打つ核から流れ出し、核の近くでは密でゆっくり、先端では疎く疾走し、漂う磁気のねじれを伴います。反対側の流れは紫に暗く抑えられ、ジェットの先端は橙色の三日月状のプルームに覆われています。**M87** は、反対側のジェットがドップラー効果で暗くなって見えなくなるため、有名な*片側だけ*のジェットを保っています。
- **太陽系ガイド** — **太陽系**ビーコンをたどり、6 秒の**ワームホール**をくぐって完全な 3D の太陽系へ。太陽、八つの惑星すべて、月、ケレス、冥王星、さらに有名な 7 つの衛星が、実際の NASA ベースの映像（主要な天体はデスクトップで 4K、タッチデバイスで 2K）をまとい、太陽に置かれた 1 つの太陽光源だけで照らされています。どの天体もクリックするとイラスト付きの 5 言語対応カードが開き、**この天体へ飛ぶ**を押すと、公転中の惑星の上空へ舞い込み、衛星が現れる中を惑星と*並んで進み*ます。**生きた太陽**は漂う粒状斑と移動する黒点をどの倍率でも保ち、近づくと真珠色のコロナのリングと、噴き出しては拡散するプロミネンスも見せます。カークウッドの空隙を備えた実スケールの**小惑星帯**、**カイパーベルト**、巨大惑星のかすかなリング、そして半透明の**大気の縁の輝き**が情景を完成させます。**彗星**が離心率の高い軌道をめぐり、太陽の近くで古典的な二本の尾 — まっすぐな青い**イオンの尾**と湾曲した白い**ダストの尾** — を広げます。クリックすればその仕組みを読めますし、**追いかける**こともできます。公転と自転は観察しやすいよう意図的にゆっくりにしています。表示縮尺と初期位置は読みやすさのためのもので、実寸の縮尺模型やリアルタイムの天体暦ではありません。
- **星座の空ビュー** — 地球のカードから、大気の白い閃光を抜けて、地球中心で回転できる星空ドームへ。実在の J2000 の恒星位置から描かれた **25 星座**（黄道 12 星座に加えて有名な 13 星座）と、それぞれ本来の母星座の中に配置された **7 つの系外銀河**があり、いずれも専用の 5 言語対応の写真カードを備えています。黄道星座を選ぶと、その姿が頭上に金色で浮かび上がります——きらめくワイヤーフレームの上で、その星座自身の星々が瞬きます。
- **5 言語対応** — ラベル、カード、ナビゲーションは英語・簡体字中国語・繁体字中国語・日本語・韓国語に切り替えられます（右上のセレクターで選択。設定は記憶されます）。
- **シネマティックな画づくり** — 選択的な bloom + ACES トーンマッピング。
- **パフォーマンスへの配慮** — FPS ウォッチドッグが非力な GPU ではダスト密度・解像度・ブルームを段階的に下げるため、ノート PC やテレビ、キオスク端末でも滑らかに動作します。

## 🚀 インストールと実行

**インストールは不要です。** ファイルを取得して HTTP で配信するだけです（`file://` プロトコルでは、オーディオやテクスチャなど一部の機能がブラウザによってブロックされます）。

```sh
# 1. get the code
git clone https://github.com/zjoooooo/galaxy-explorer.git
cd galaxy-explorer

# 2. serve it with any static server, e.g.:
python -m http.server 8000
#   or:  npx serve .
#   or:  php -S localhost:8000

# 3. open http://localhost:8000/
```

**静的ホスティングならどこにでもデプロイ可能:** GitHub Pages、Netlify、Vercel、Cloudflare Pages、S3、nginx、その他任意の Web ホスト。フォルダーをアップロードするだけで、ビルドするものは何もありません。

## 🎮 操作方法

| 操作 | 効果 |
|---|---|
| **ドラッグ** | カメラを周回させる |
| **スクロール / ピンチ** | ズームイン / ズームアウト |
| **ビーコン・天体・彗星をクリック** | カードを開く。天体を選んでもカメラと運動は変わらない |
| **この天体へ飛ぶ / この彗星を追いかける** | （カード上）動いている対象の上空へ舞い込み、並んで進む |
| **戻る** | 星空 → 地球 → 太陽系の全景 → 銀河の順に 1 段階戻る |
| **`Esc`** | 段階的に戻る：カードを閉じ、現在の太陽系レベルを離れ、最後に太陽系を離れる |
| **`F`** | シネマモード — すべての UI を非表示 |
| **`M`** | BGM のオン / ミュート（任意。下記参照） |

**URL パラメーター**

- `?fx=1` — デモモード: 流れ星・流星群・超新星を 4 秒ごとに強制的に発生させ、アンビエントエフェクトをすぐに確認できます。

## 🎛️ カスタマイズ

`index.html` を開き、`<script>` の冒頭付近にある **tunables** ブロックを編集します。

```js
var BLOOM = { strength: 0.08, radius: 0.32, threshold: 0.42 }; // glow
var DUST  = { count: 30000, radius: 360, arms: 4, tight: 0.85, brightness: 0.5, ... };
var GALAXY_SPIN = 0.013; // rotation speed (radians/sec)
```

- `DUST.count` — 星・ダストの総数（非力なハードウェアでは下げてください）。
- `DUST.arms` / `DUST.tight` — 渦状腕の本数と巻きの強さ。
- `BLOOM.strength` — 全体のグロー（0 でオフ）。
- `GALAXY_SPIN` — 銀河全体の回転速度。

## 🎵 BGM

`audio/` に 3 曲のアンビエントトラックが同梱されており、**読み込み時に自動再生されます**（自動再生をブロックするブラウザ向けに、最初の操作をきっかけに再生するフォールバック付き）。右下のスピーカーボタンか `M` キーでミュート / 解除でき、ボタンにホバーすると曲名でトラックを選べます。トラックはループ再生されます。

音楽を変更するには、自分の `.mp3` ファイルを `audio/` に置き、`index.html` 内の `MUSIC_TRACKS` にファイル名を列挙します。

```js
var MUSIC_TRACKS = ['ambient 1.mp3', 'ambient 2.mp3'];
```

`MUSIC_TRACKS` を空にすると、スピーカーボタン自体が非表示になります。
**共有する権利を持たない著作権付き音源はコミットしないでください。**

## 🛠️ 仕組み（概要）

Vanilla JavaScript + three.js r128（`vendor/` 以下に同梱）。自己完結した 1 つの `index.html` だけで構成されています。銀河は読み込み時に一度だけ構築されます。

1. 密度波の渦状腕に沿ってダストポイントを散布します（`Points` のクラウド）。
2. フラグメントシェーダーが円盤を一度だけテクスチャに描き込み（ノイズを渦巻きの流れに沿って線積分畳み込みで引き伸ばす）、近づくと円盤はフェードアウトします。
3. スプライトのグローがバルジを形作り、またたく遠方の球体が背景の星空になります。
4. プロシージャルなテクスチャアトラス + ビルボード化したクアッドのバッチで遠方銀河を描画します。
5. ポストプロセス: `UnrealBloomPass` でグローをかけ、その後 ACES トーンマップのパスを適用します。

アンビエントエフェクト（流星や超新星）は、スケジュールに従って生成されては自ら破棄される短命のオブジェクトです — アイドル時のフレームあたりの定常コストはゼロです。

太陽系は、ワームホールのトランジションを通じて入る第 2 のシーンです。その惑星は太陽に置かれた 1 つのポイントライトで照らされ、同梱の NASA / Solar System Scope のマップ（初回入場時に読み込み）でテクスチャリングされます。彗星、ジェット、プロミネンス、尾は、毎フレーム、事前確保したバッファに書き込まれるパーティクルシステムです。
